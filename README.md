# Insurance Claims Portal

A full-stack web application for submitting Voluntary Health Insurance Scheme (VHIS) claimable amount estimates. Built with React, Node.js, Express, and MongoDB.

## Features

- User registration and login with JWT authentication
- Complete VHIS claimable amount estimate form
- Bilingual support (English/Chinese)
- Automatic total calculation for estimated charges
- Secure password hashing with bcrypt
- MongoDB database integration
- Professional insurance portal UI

## Tech Stack

**Frontend:** React 19, CSS-in-JS, Fetch API  
**Backend:** Node.js, Express.js, JWT, bcryptjs  
**Database:** MongoDB, Mongoose

## Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- MongoDB (local or Atlas)
